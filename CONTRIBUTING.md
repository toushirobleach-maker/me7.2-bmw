# Участие в проекте

Вопросы, ошибки и новые данные предлагайте через Issues. Изменения кода и документации — через fork и Pull Request. Права прямой записи участникам не выдаются; изменения основной ветки проходят через PR и сливаются владельцем.

Начните с README.md и AGENTS.md. Для исправлений приводите источник, адреса, ожидаемый результат и способ проверки. Различайте гипотезу, проверку байтов и подтверждение функционального смысла.

Перед PR выполните офлайн-проверки:

```sh
python3 -m unittest discover -s 08_tests -v
python3 09_re_tools/check_public_tree.py
```

После изменения публичных файлов обновите MANIFEST_SHA256.json и проверьте его. Генератор по умолчанию не перезаписывает существующий манифест: создайте новый с `--file` во временном пути и замените проверенный файл.

Не прикладывайте дампы автомобиля, изменённые BIN, VIN, идентификаторы, сырые security/transfer-логи или личные пути. Из BIN допустим только включённый аналитический stock по фиксированному SHA. Полный Funktionsrahmen, выгрузки его страниц и ссылки на документ или содержащие его архивы не принимаются. Внешние входы храните локально по LOCAL_ASSETS.json. Происхождение и условия использования компонентов описаны в NOTICE.md.
