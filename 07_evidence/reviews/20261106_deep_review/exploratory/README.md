Промежуточные материалы поиска, сохранённые для истории.

Файлы *_raw_decoder.asm содержат известные ошибки исходного декодера bitoff, MOVBZ и EXTP. Автоматически найденные кандидаты могут начинаться внутри инструкции или содержать совпадение операнда из другой страницы памяти. Названия файлов передают прежнюю гипотезу, не установленную функцию. Они НЕ являются подтверждёнными адресными определениями. Для выводов использовать REVIEW_RU.md, ключевые листинги в родительском каталоге и key_evidence_verification.json.
