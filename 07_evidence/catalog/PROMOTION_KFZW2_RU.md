# KFZWOP / KFZW1 — pass-2 (адресный consumer)

KFZWOP @`0x10220`: **STILL_STRUCT**  
KFZW1 @`0x10BC2`: **STILL_STRUCT**

Декодер только `review_decode.py` (калибровка `9F17` / `D7400602` / `C2F43016` — OK).  
FR: KFZWOP ∈ MDBAS p.50–51; KFZW1 ∈ ZWGRU p.208–209 — семантика OK, адреса нет.

В PROVEN / патч не поднимать.

## Вердикт

| Объект | file → CPU | Вердикт | Размер / шкала |
|---|---|---|---|
| KFZWOP | `0x10220` → `0x810220` (стр. `0x204`, mem `0x0220`) | STILL_STRUCT | 16×16 / 0.75° — **перенесено** (E5A0) |
| KFZW1 | `0x10BC2` → `0x810BC2` (стр. `0x204`, mem `0x0BC2`) | STILL_STRUCT | 16×24 / 0.75° — **перенесено** (E5A0) |

## Pass-2 стратегии (все FAIL на consumer)

### 1) Xref на cal-слова `0x817946` / `0x8179AC`

Phys на **DPP1 / page `0x205`**: logical mem16 = `0x7946` / `0x79AC` (не page 206).

| Поиск | Счёт |
|---|---|
| LE `46 79` (`0x7946`) во всём BIN | **0** |
| LE `AC 79` (`0x79AC`) | **0** |
| `MOV Rn,#0x7946` / mem `0x7946` | **0** |
| EXTP `#206` ×1716 → mem из watch-set | **0** |
| EXTP R-form → mem `0220`/`0BC2` | **0** |

Ближайший код: `0x867F88` `F2FC4479` **MOV R12,0x7944** → в R12 попадает значение **`0x2CBC`**, не слово `+2` (`0x0220`). Далее `R13←[0x79BE]=0x2EBC`, `CALLS 0x00,0x791A` (тело в дампе по `0x80791A` = `FFFF`, типичный internal-ROM/seg0). Это consumer другой базы, не KFZWOP.

### 2) Дескрипторы интерполяторов / R12 из таблицы

- Пар `MOV R12,#imm; MOV R13,#0x204` + CALLS: **0** (все far-ptr карты — page **`0x206`**).  
- `MOV Rn,#0x7940…0x79C0` (база для `[Rp+]`): **0**.  
- `MOV R12,#0x0220` / `#0x0BC2`: **0**.

### 3) Заголовки у карты

Перед `0x10220` / `0x10BC2` локального hdr `16×16` / `24×16` нет (COM_AXIS снаружи — как в E5A0). Размерности с 6901-кода не восстановлены.

### 4) FR full index

MDBAS/ZWGRU + имена KFZW* — **доказано текстом FR** как роль семейства. ASCII `KFZW`/`ZWGRU` в BIN: **0**.

### 5) DPP0 / «разрезный» imm

- `MOV`/`MOVBZ Rn,0x0220` и `…,0x0BC2`: **0**.  
- Ложные `ADD …,0x0220` @`0x858CBF` / `0x86F43F` (SFR).  
- Сырые `C2 0B`: ось `@0x1348E` (breakpoint), cal-слово `@0x179AC` — не `MOV #imm`.

### 6) Строки

Нет ASCII-якоря для дизасма ZWGRU/MDBAS.

## Что это доказывает / не доказывает

**Доказано кодом (негатив):** в 512 KiB flash нет видимого адреса consumer’а `0x810220` / `0x810BC2` ни прямым imm, ни EXTP#204/205, ни DPP1-слотом `0x7946`/`0x79AC` (сами LE-адреса слотов в образе отсутствуют).

**Не доказано:** что байты «мертвые» — car-dump их меняет; возможен путь через internal ROM / runtime-указатель без imm в этом дампе.

**Гипотеза / перенос:** имя, 16×16 / 16×24, signed 0.75° — FR+E5A0, не 6901-consumer.

Пробел для PROVEN_ADDR: сайт, где база `0x0220`/`0x0BC2` (стр. `0x204`) реально уходит в интерполятор.
