## Что искали (и не нашли)

Страница для `0x81xxxx`: `phys = page·0x4000 + (mem&0x3FFF)` → `0x810220` = page `0x204`, mem `0x0220` (DPP0).

1. **`MOV Rn,#0x0220` / `#0x0BC2`** — 0 попаданий во всём BIN.  
2. **Far-ptr** `MOV R12,#off; MOV R13,#0x204/#205/#206` — нет (в отличие от термостата `R12=#1B80`, page `206`).  
3. **`EXTP #0x204/#0x205`** — census **0 / 0** (при `#0x206` = 1716). Окон с mem `0220`/`0BC2` нет.  
4. **Packed** `20 02 04 02`, `C2 0B 04 02` и phys LE `0x810220`/`0x810BC2` — нет.  
5. Ложные следы: `0x8211A4 MOV R4,#0x0320` + `DIVLU` — делитель, не база карты.

## Косвенные находки (не consumer)

- В cal @`0x817946`: слова `0220 0320`; @`0x8179AC`: `0BC2 0D42 0EC2`. Совпадение с оффсетами KFZW* есть; **xref из кода на `0x7946`/`0x79AC` (DPP1) не найден** → не доказательство потребления.  
- `0x85276C`: `R12=#0x19BD` → ось `0x8119BD` (E5A0 SNM24ZUUB) через `CALLS 74DA` — ось без z-базы `0x0BC2`.  
- `0x868000`: `R12=#0x1F36`, `R13=#0x19BD` — другая карта (`0x811F36`), не KFZW1.

## Шкала signed 0.75°/LSB

**На 6901 для KFZWOP/KFZW1 — не доказано.**

- E5A0 `zw_sb_q0p75` (191.25/255=0.75) — **перенесено из другого SW**.  
- FR PROKON: `SY WMAX 72 ↔ 54°KW`, `SY WMIN −32 ↔ −24°KW` → фактор 0.75 для **SY-констант угла**, не xref на байты KFZW*.  
- Stock-ячейки KFZWOP/KFZW1 все `<0x80` — знак по данным не виден.  
- Строк `KFZWOP`/`KFZW1` в `10_review` FR_* нет.

## Недоказанный пробел

Нужна инструкция (или доказанный обход таблицы), которая загружает базу `0x810220` / `0x810BC2` в интерполятор; затем с этого пути — размерности и (отдельно) signed×0.75.

Car-dump (+3 LSB на OP, +4 на KFZW1 по всему span) подтверждает «живые» байты, не Bosch-имя и не consumer.
