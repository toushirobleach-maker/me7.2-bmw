# MSLBAS @ `0x19612` — промоушен

**Вердикт: STRUCT_NEW_NAME** — `AF2C_AF2D_INIT_SCALAR`; имя Bosch **MSLBAS** остаётся **гипотезой** (не PROVEN).

Декодер: `10_review/20261106_deep_review/tools/review_decode.py` (калибровка `9F17`→`FD2E.9`, `D7400602`, `C2F43016`).  
BIN/сток: `ME72_7532675_full_512KiB_…` / stock G7533626; байт сток=`1D` = дамп. DPP0/1/2 = `0x204/205/0E0`.

XDF-title при листинге: **`[STRUCT] AF2C/AF2D init seed → 8A8D/8A8E (MSLBAS unproven)`**.

## Тройка доказательств

| # | Статус | Суть |
|---|---|---|
| 1 consumer | **PASS** | 4× `EXTP #0x206` + `MOVB …,0x1612` → phys **`0x819612`** |
| 2 семантика | **PARTIAL** | Роль init-seed **доказана кодом**; имя MSLBAS / SAP-масса / zero-off — **нет** FR/DTC/live |
| 3 фальсификаторы | см. ниже | «кусок MSLUB» и «только порог» — DID_NOT_FIRE; «база в произведении MSLUB» — **FIRED** |

| CPU | RAW | Текст → phys |
|---|---|---|
| `849C7A` | `D7400602 F3F81216` | `EXTP #206,#1; MOVB RL4,0x1612` → `0x819612` → `AF2C` |

Ворота init-ветки: `849C76 JNB FD4A.4`. Других EXTP#206+`0x1612` в BIN нет.

## Что делают с значением (доказано кодом)

Не сравнение с порогом и **не** сложение с MSLUB:

1. Сид: `0x819612` → `AF2C` / `AF2D`.
2. Копии: `AF2C`→`8A8D`, `AF2C<<8`→`8ECE`; банк2: `AF2D`→`8A8E` / `8EE2`.
3. Дальше `8ECE` фильтруется (`CALLS 0x6D7A`), обратно в `8A8D`; `AF2C` обновляется из `8A8D`.
4. `8A8D` — **делитель** (`DIVU` с `8A89<<7` → `8A9B`); аналог банка2 с `8A8E`.

Сосед `0x19613` — отдельные `CMP` (порог), не этот байт.

## FR / MSLUB / CLASLPE

- FR SLS/BMSL: есть **MSLUB**, MSLSTAT, MSLPUB, формула `msl` из KL MSLUB×поправки; строки **MSLBAS нет**.
- MSLUB: ptr `0206:16A9` @`84C7EA` → `8AA6`. В окне `84C7EA..84CA80` чтений `0x1612` / `AF2C` / `8A8D` / `8ECE` **нет**.
- CLASLPE / `0x153F2`: связи с `0x19612` нет.
- Чужой A2L/XDF (E650/E5A0/e18/community 6901) зовёт байт MSLBAS — **перенесено**, не evidence_2.

## Фальсификаторы

1. «Это объект кривой MSLUB (`0x196A9`)» → ждали far-ptr `0x16A9` — **DID_NOT_FIRE**.
2. «Аддитивная/мультипликативная база в продукте MSLUB» → ждали чтение рядом с `8AA6` — **FIRED** (связки нет).
3. «Только порог как `0x1613`» → ждали `CMPB` на load — **DID_NOT_FIRE** (сид в RAM).

## Что нужно для PROVEN MSLBAS

Один якорь: ярлык **6901I41D**, что phys `0x819612` = Bosch **MSLBAS** (FR / DAMOS-A2L этой сборки / live), **либо** доказательство, что `8A8D` (питаемый этим сидом) = FR-сигнал `msl` / `mslstat`.

Без этого в патч/PROVEN-XDF под именем MSLBAS не поднимать; STRUCT только под `AF2C_AF2D_INIT_SCALAR`.
