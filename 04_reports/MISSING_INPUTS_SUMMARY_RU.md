# Недостающие материалы: короткий список

Полный машинный список всех ссылок/отчётов/строк — [REPORT_REFERENCES.json](REPORT_REFERENCES.json); классификация — [REPORT_REFERENCES_RU.md](REPORT_REFERENCES_RU.md).

## 10 действительно отсутствующих имён файлов из отчётов

| Файлы | Для чего нужны |
| --- | --- |
| independent_binary_audit.py, verify_key_evidence.py | Точное повторение исторического глубокого ревью, не обычная проверка checksum |
| audit_v2.py, rebuild_traces.py | Старые проверки/трассы второй версии |
| me72_dtc_code_xref.py | Восстановление/проверка DFPM→DTC-сопоставления; runtime DTC-reader использует уже включённые tables |
| REVIEW_IMMO_88C_IGN.md, REVIEW_LREB_FORM.md | Текстовые обоснования, на которые ссылаются promotion-материалы |
| Findings.txt | Упомянутые прежние заметки; содержимое не включено |
| 6901.xdf, 6901.6902.ME72.xdf | Старые community definitions; они не заменяют текущий доказательный каталог |

Часть имён встречается под несколькими старыми путями. Наличие новых05_tools/verify.py или09_re_tools/audit_repo.py не означает, что эти старые программы воспроизведены.

## Внешние/локальные входы, отсутствующие намеренно

- Исходные matching .0PA/.0DA/.DAT для штатного программирования и подготовки stock overlay. В Git оставлен только аналитический BIN с описанием.
- E5A0_000.a2l и E650_000.a2l для сопоставления другой сборки; абсолютные адреса из них не считаются доказательством6901.
- 10EK726.prg/IPO, me72kwp1.prg и производные полные листинги — для независимого исполнения/разбора OEM jobs. Основная CLI работает без них.
- FR_813_ESKONF.png, FR_885_PROKON.png и FR_relevant_pages.txt/JSON — производные reference-выгрузки. Полный FR PDF, полный текст/страницы и ссылки на документ/архив не публикуются.
- IROM/внутренняя ROM или трасса соответствующих потребителей — этот пробел не устраняется копированием ещё одного XDF.

## Частные артефакты, которые не нужно возвращать

Дамп машины, производные/установленные сборки, patch-build результаты, raw DTC/λ/RAM/security/wire logs и real-cal OEM_ORACLE. Их отсутствие намеренное; часть исторических case-specific выводов без них не воспроизводится из public clone.

Полное поле `status` различает bundled_exact, relocated/basename, local inputs, private exclusions, действительно missing dependencies и символические примеры. Формальная проверка одних DAMOS-basename недостаточна для вывода «все отчёты воспроизводимы».
