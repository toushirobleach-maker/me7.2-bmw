# Происхождение и права

Единственный включённый firmware BIN — аналитическая реконструкция BMW SP-Daten по выбору владельца пакета. Происхождение и ограничение37/38 описаны в00_stock. Наличие файла здесь не устанавливает право любого лица на его дальнейшее распространение; общая лицензия на firmware/BMW/Bosch материалы не объявляется.

Полные reference PDF, full FR text, SP-Daten raw sources и donor images не включены. По решению владельца нет ссылок на полный FR PDF или содержащие его архивы. Индексы/небольшие кодовые доказательства не являются полным документом.

05_tools не импортирует GPL-decoder. Лицензию на собственный код выбирает владелец до распространения с соответствующей лицензией; она не приписывается сторонним материалам. Pyserial3.5 устанавливается отдельно. NPM parser/interpreter нужны только для независимой регенерации синтетических fixture из собственных BMW jobs, а не для основной CLI.

SOURCE_MAP фиксирует публичные snippets и преобразования. Манифест подтверждает байты перечисленных public files, не их подлинность/права или пригодность для прошивки. Локальные входы и результаты исключены из него.
