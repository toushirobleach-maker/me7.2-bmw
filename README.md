# Bosch ME7.2 · 7532675 · 6901I41D

Публичный исследовательский пакет: каталог калибровок, XDF, протокол K-line и отдельные инструменты чтения, записи и контрольных сумм. Поддерживается конкретная компоновка 6901I41D; совместимость со всеми ME7.2 не заявляется.

**Начать:** [инструкция](03_docs/START_HERE_RU.md) · [команды](03_docs/TOOLS_RU.md) · [как работать со стоком SP-Daten](03_docs/STOCK_FLASHING_RU.md) · [идентификаторы и DAT→BIN](03_docs/SP_DATEN_TO_BIN_RU.md) · [чего не хватает отчётам](04_reports/REPORT_REFERENCES_RU.md) · [AGENTS](AGENTS.md).

## Что включено

| Материал | Состояние |
| --- | --- |
| Аналитическая реконструкция SP-Daten | Единственный BIN; исходные байты сохранены. **37/38** checksum, напрямую не записывать |
| Каталог | 632 записи: 155 PROVEN,99 STRUCT,298 HYP,80 UNLINKED |
| XDF | Полный каталог552 объектов и узкий исторический snapshot56 |
| Инструменты | Read / write cal64 / verify / checksum-fix; доступ к устройству только с явным `--execute` |
| Тесты | Искусственные данные и OEM-векторы, без дампа конкретного автомобиля |
| Исследовательские доказательства | Листинги, promotion-отчёты, индексы; отсутствующие входы явно перечислены |

Исходный дамп машины, установленные/экспериментальные сборки, cal64, сырые логи, seed-ответы машины и полные журналы передачи не распространяются. Сток SP-Daten не заменяет собственный backup. Полный FR PDF не включён; ссылки на него и содержащие его архивы не предоставляются.

## Отдельные команды

| Команда | Назначение |
| --- | --- |
| [read.py](05_tools/read.py) | Полные512 КиБ / DTC / три RAM-слова / λ-лог |
| [write.py](05_tools/write.py) | План и запись **только cal64**, исходя из собственного проверенного baseline |
| [verify.py](05_tools/verify.py) | 38 проверок и сравнение файлов / полное сравнение с ECU |

| [prepare_stock.py](05_tools/prepare_stock.py) | Офлайн-кандидат заводских калибровок из собственной базы и своих .0PA/.0DA |

```sh
python3 -m unittest discover -s 08_tests -v
python3 05_tools/read.py --kind flash
python3 09_re_tools/query.py KRKTE --json
python3 09_re_tools/check_public_tree.py
```

`read`/`write` без `--execute` только показывают план. Офлайн-часть — Python3.10+ и стандартная библиотека; USB требует pyserial3.5.

## Сток: сначала прочитать

[Включённый BIN](00_stock/ME72_7532675_6901I41D_stock_from_G7533626_512KiB.bin) получен объединением `7532675A.0PA` и `G7533626.0DA` в окно512 КиБ с заполнением пробелов FF. SP-Daten покрывают489750 байт, не весь физический чип. В cal не покрыты904 байта, включая хвост и end marker; одна ROMSYS-сумма не сходится. Исправить суммы недостаточно, чтобы восстановить отсутствующие данные.

Для штатного полного программирования использовать подходящий OEM-процесс с правильным ZUSB/вариантом. Для нашего cal-only writer нужен собственный полный исправный baseline и совместимый программный код; [prepare_stock.py](03_docs/STOCK_FLASHING_RU.md) сохраняет непокрытые байты и известные служебные поля. Подбор варианта, кодирование и EWS — отдельные вопросы; ручная вставка VIN не делает чужую прошивку совместимой.

## Структура

- `00_stock/` — исходная аналитическая реконструкция, SHA и происхождение.
- `01_damos/`, `02_xdf/` — каталоги и определения.
- `03_docs/` — актуальные инструкции и ограничения.
- `04_reports/` — текущий аудит, список отсутствующих ссылок, исторические summaries.
- `05_tools/` — активная библиотека/CLI.
- `07_evidence/` — публичные листинги, отчёты и синтетические factory-векторы.
- `08_tests/`, `09_re_tools/` — имитаторы, аудит, C166-декодер, генератор XDF.
- `10_references/` — индексы/метаданные; полные документы не размещаются.
- `local/`, `runs/` — собственные входы и результаты пользователя, исключены из Git.

[LOCAL_ASSETS.json](LOCAL_ASSETS.json) описывает внешние входы. [Публичный состав](03_docs/PUBLIC_RELEASE_RU.md), [ограничения доказательств](03_docs/EVIDENCE_AND_LIMITS_RU.md), [NOTICE](NOTICE.md). Новая упаковка и подготовка стока проверяются офлайн; это не квалификация произвольной калибровки или полной записи512 КиБ.
