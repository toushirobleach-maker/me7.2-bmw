# Определения TunerPro

| Файл | Объекты | Фактические теги |
| --- | --- | --- |
| ME72_7532675_6901I41D_from_damos.xdf | 552 | 155 PROVEN, 99 STRUCT, 298 HYP |
| ME72_7532675_6901I41D_proven.xdf | 56 | 44 PROVEN, 12 STRUCT |

Разные наборы отражают полный каталог с привязанными адресами и более узкий исторический manifest. Имя proven.xdf не означает, что все его элементы PROVEN. 80 UNLINKED-записей каталога не имеют готовых XDF-объектов. Статусы отдельных записей в двух snapshots могут различаться; канонический текущий каталог — `01_damos/damos_lite.json` с прикреплёнными доказательствами.

Открывать полный BIN в TunerPro, затем выбранный XDF; адреса — file offsets. Образы SP-Daten и машины различаются, сохранённые stock_hex и patch preconditions могут быть рассчитаны на конкретную основу. XDF сам checksum не исправляет.

Генератор: [09_re_tools/generate_xdf.py](../09_re_tools/generate_xdf.py). Новый выход задаётся явно, исходные XDF не заменяются. Счётчики GENERATION_REPORT уточнены по текущему каталогу; прежний отчёт сохранён в evidence/catalog. Сами XML-байты при упаковке сохранены.

Обязательно прочитать [ограничение SP-Daten](../03_docs/CHECKSUMS_RU.md) и [правила доказательств](../03_docs/EVIDENCE_AND_LIMITS_RU.md).
