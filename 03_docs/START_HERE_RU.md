# Начать здесь

Это публичный пакет исследования одной компоновки ME7.2. Сначала прочитать [stock guide](STOCK_FLASHING_RU.md), [DAT→BIN](SP_DATEN_TO_BIN_RU.md), [политику публикации](PUBLIC_RELEASE_RU.md) и [ограничения доказательств](EVIDENCE_AND_LIMITS_RU.md).

1. Проверить тесты: `python3 -m unittest discover -s 08_tests -v` — не требуется дамп машины.
2. Найти символ: `python3 09_re_tools/query.py KRKTE --json`.
3. Открыть consumer/promotion-отчёт; отделить исходные данные от доказательства смысла.
4. Проверить [реальные missing references](../04_reports/REPORT_REFERENCES_RU.md). Старый путь или найденный basename не гарантирует нужный файл/версию.
5. Для собственных операций использовать только `05_tools/`, свои inputs в `local/`, outputs в `runs/`.

Единственный включённый BIN — аналитическая реконструкция SP-Daten37/38. Нет полного рабочего donor image, установленной сборки или частной калибровки. Утверждения прежних испытаний не превращают эти входы в общедоступные доказательства.

Новые каталоги не «официальный полный DAMOS»:632 записи со статусами155 PROVEN,99 STRUCT,298 HYP,80 UNLINKED. Полный XDF содержит552 привязанных объекта, узкий исторический —56. Полный FR не включён, ссылок на него нет; индексы дают только названия/страницы.
