# Механизм SAP → запрет LR

Код этой сборки @87582C..87584C объединяет FD8E.13,FD72.9,FD42.6,B9CC.0 (SLP) иB9D6.0 (SLV). Результат —FDD8.9, который копируется вFDD8.10 второго банка. Эти запреты участвуют в условиях установки FD2E.9/.10 —B_lr/B_lr2.

Для inactive=11 в ESKONF описан путь инициализации с очисткой функционального fault bit0 соответствующего выхода. Поэтому корректная конфигурация отсутствующего SAP может снять его вклад в запрет; одно подавление строки DTC этого не доказывает. Конфигурация зондов/готовность, температурные/стартовые условия и другие источники запрета остаются отдельными условиями.

В историческом случае описано изменениеFDD8 с2610 на2010 и включение обоих регуляторов. Исходные raw trials/donor firmware в публичной версии отсутствуют; это историческое наблюдение, не повторно воспроизведённый публичный benchmark и не доказательство единственной причины.
