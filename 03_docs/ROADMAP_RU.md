# Следующие исследовательские задачи

| Вопрос | Что уже есть | Чего не хватает |
| --- | --- | --- |
| Переносимый writer | Код, 128-byte ACK, exact postcycle check, fake fault tests | Отдельное аппаратное испытание именно новой упаковки, когда пользователь явно попросит |
| SP-Daten reconstruction | Исходные 0PA/0DA-параметры, SHA, 489750 bytes coverage | Восстановление происхождения недостающих участков/маркера; не вставлять по предположению |
| Полные карты KFZW/page204 | Адресные/структурные кандидаты, FR, дескрипторы | IROM либо трасса, подтверждающая consumer этой сборки |
| Lambda long-term | B_lr обоих банков, FR меняются | Прогретый лог и несколько устойчивых режимов для обучения |
| Экономия топлива | Прежняя жалоба | Сопоставимое измерение расхода до/после |
| Digital SGBD interpreter | Сохранены raw 4007/4005 и нулевые результаты JS job | Разобрать сборку буфера/семантику интерпретатора; пока использовать прямую RAM |
| UIF view | 75 служебных отличий только в programming read, exact match после cycle | Установить механизм overlay/подстановки и момент обновления |
| Быстрый RAM-логгер | 9600: около 63 мс на слово, проверенные RAM-адреса | Блочное чтение соседних переменных и тест ускоренной сессии на работающем DME |
| Полная запись / recovery | Изученные исходники внешних проектов, отдельные ROM-вызовы | Валидированная граница erase всех секторов и практический путь восстановления |

Ни одна задача здесь не означает автоматическое разрешение обращаться к автомобилю. Продолжать по конкретному запросу пользователя, фиксируя новый SHA и границы вывода.

## Публичная воспроизводимость

Сначала разбирать отсутствующие зависимости из04_reports/REPORT_REFERENCES_RU.md. Private raw trials не возвращать в public Git. Полного FR и download-ссылок не добавлять. Новый stock overlay требует отдельного аппаратного испытания по явному запросу владельца соответствующего автомобиля.
