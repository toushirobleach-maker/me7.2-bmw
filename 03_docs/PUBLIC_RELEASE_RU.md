# Состав публичной версии

Включены собственные инструменты, каталоги/индексы, ограниченные кодовые доказательства и один аналитический BIN из SP-Daten. Полные исходные SP-Daten, PDF и документы пользователь импортирует локально при наличии своих файлов. Полный FR PDF и ссылки на него/его архивы исключены по выбору владельца.

## Что удалено из публичного состава

- Исходный vehicle-dump, минимальная и установленная/экспериментальные сборки, cal64.
- Сырые DTC/λ/RAM/wire/security логи и реальные seed fixtures.
- OEM_ORACLE с полным cal: эти JSON позволяли восстановить64 КиБ без BIN.
- Конкретный USB serial, ECU/vehicle identifiers и домашние пути.
- Полные factory-дизассемблировки и private-target patch/build scripts. Активная generic CLI сохранена.

Полевые утверждения в исторических отчётах являются описанием прежней работы; отсутствие сырых входов ограничивает независимое воспроизведение. Их не нужно возвращать ради нулевого missing-reference счётчика.

## Локальные материалы

[LOCAL_ASSETS.json](../LOCAL_ASSETS.json) задаёт имена/роли. Импорт своих SP-Daten:

```sh
python3 09_re_tools/import_local_assets.py --program /path/to/7532675A.0PA --data /path/to/G7533626.0DA
```

Команда создаёт gitignored `local/sp_daten/` и аналитическую реконструкцию в `local/stock/`. Не скачивает файлы и не подключается к ECU. Существующие файлы не заменяет. Собственные PDF/A2L можно импортировать соответствующими параметрами `--help`; download-ссылки на полный FR не предоставляются.

## Проверка перед публикацией

```sh
python3 -m unittest discover -s 08_tests -v
python3 09_re_tools/check_public_tree.py
python3 09_re_tools/manifest.py verify
```

Проверка public tree допускает только точный stock BIN по SHA; блокирует прочие BIN/полные документы/сырьё/log-файлы, известные классы personal paths/VIN/USB serial и не-синтетические transfer fixtures. Это техническая проверка конкретных правил, не юридическое подтверждение прав и не универсальное доказательство отсутствия любой персональной информации.

Старая `.git` с прежними BIN/PDF и личными материалами сохранена вне публичной папки в приватном архиве. Для публичной версии создана новая Git-история; рабочие файлы сохранены. Прежняя история с частными материалами в неё не входит. Перед публикацией повторены проверки состава. Изменения основной ветки принимаются через PR; вопросы и ошибки — через Issues. Происхождение/права отдельных компонентов — [NOTICE](../NOTICE.md).
