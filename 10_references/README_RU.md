# Индексы и внешние материалы

В Git оставлены метаданные применимости, индексы функций/страниц и сведения о сторонних источниках. Полные PDF, полнотекстовая выгрузка и raw SP-Daten сюда не включены. Полный FR на1043 страницы и ссылки на него/содержащие его архивы не предоставляются.

`fr_index/symbol_pages.json` и очищенный `FR_FULL_INDEX.json` дают имена/номера страниц, не полный текст и не абсолютные адреса калибровок. Контекст другой ревизии подтверждать consumer текущей6901I41D. Заголовки/термины reference сами по себе не повышают HYP доPROVEN.

[LOCAL_ASSETS.json](../LOCAL_ASSETS.json) перечисляет optional user-owned материалы. Копирование своих входов выполняет `09_re_tools/import_local_assets.py` в gitignored local/. Нехватающие ссылки старых отчётов классифицируются отдельно.
